## Teach

Place up to five objects in a row. Point to each object as you count aloud. Emphasize that the last number tells how many objects are in the group.

## Model

Show three counters. Touch each counter once: one, two, three. Say: There are three counters.

## Guided practice

Ask the learner to count a new set. If an object is skipped or counted twice, reset the set and count together slowly.

## Independent check

Show a set of four objects and ask: How many are there?
